# Moving Centres / 독립 중심의 연속 회전

## 사용자 피드백과 이번 수정
흑백 figure–ground와 방향별 해치 표현은 유지하고, 동일 방향의 복사 배열을 바꾼다. 세 날개가 합쳐진 M4 전체를 하나의 모듈 U로 다룬다. 20개의 U는 각각 다른 중심 P와 다른 회전각 θ를 가진다. 외곽의 불규칙함은 원형을 무작위로 찌그러뜨려 만든 것이 아니라 연속적인 위치·각도 규칙의 결과다.

이전 제출물은 12개였지만 이번에는 흐름을 더 넓게 읽기 위해 20개를 사용했다. 모듈 수 증가와 배열 변화의 효과를 혼동하지 않도록 규칙 설명 보드의 시작 배열도 똑같이 20개로 그렸다. 9개 비교안 역시 모두 20개다.

## 무엇을 유지하는가
source-study.json의 M4를 직접 읽는다. 세 날개 1.25u × 0.80u, 중심 반경 0.45u, 중심 방위 150°/30°/270°, 각 날개의 장축은 해당 방위 +15°다. U의 내부 삼중 교집합 T는 기존 중정이다. U 자체의 세 날개 관계는 유지한 채 전체를 이동·회전한다. u는 이전 정규화 스터디의 상대 단위이며 원본 주택의 실치수가 아니다.

## 세 규칙의 비교
- FAN: 초기 격자를 곡률 반경에 따라 굽히고 각 모듈을 접선 방향으로 회전한다. 전체 흐름은 명료하지만 행과 열의 반복성이 비교적 강하다.
- COUNTER: 두 제어점에서 거리에 따라 약해지는, 부호가 반대인 회전 영향을 합성한다. 각 지역의 중심 위치와 모듈 방향이 달라져 작은 접점·넓은 접합·사선 교차가 함께 나타난다.
- STREAM: 물결 모양으로 중심을 이동시키고 접선과 행 위치에 따라 각도를 정한다. 강도 1.0 이상에서는 전체 바닥은 붙어 있어도, 0.18u 이상의 접합만 남긴 주요 연결망이 2개로 나뉜다.

각 규칙의 강도 0.65 / 1.00 / 1.35를 비교했다. 선택은 COUNTER-1.00이다. COUNTER-1.35는 접합 면적 변동계수가 더 높지만 주요 접합 수는 동일한 32개이고, 중정 침범 면적은 약 0.115u²로 커진다. 1.00은 약 0.0123u²다. 형태 차이를 더 크게 만드는 것만으로 설득력이 높아지지는 않는다고 판단했다.

## 선정안의 생성식
모든 좌표값은 u로 나눈 무차원 수로 사용한다. i=0…4, j=0…3, d=1.60.

qₓ = d [i + (j mod 2)/2 − 2.25]
qᵧ = (√3/2)d (j − 1.5)

F₁=(-2.4,0), F₂=(2.4,0), σ=2.5.
wₖ(q)=exp[−||q−Fₖ||²/(2σ²)].
φ₁=+44° w₁, φ₂=−44° w₂.

P(q)=q + 0.62 Σₖ [R(φₖ)(q−Fₖ) − (q−Fₖ)]
θ(q)=φ₁+φ₂+6°qᵧ
U′(q)=P(q)+R(θ(q))U

F₁·F₂는 방향장을 만드는 제어점이며 실제 모듈 회전축이 아니다. 실제 회전축은 각 U의 P다. 입력 형상 좌표의 원점은 모듈 중앙이다. 각 원형은 확대·축소·전단 없이 강체 변환된다. 모든 P와 θ는 pivots-and-angles.csv와 selected.json에 기록했다. 회전각 범위는 −39.638°~+39.638°다.

## 무엇이 겹치는가
단일 모듈 내부의 A/B/C 교집합과, 반복된 U끼리의 교집합을 구별한다. 이번 핵심은 U의 방향 관계가 바뀌며 생기는 후자의 다양성이다. 39개 실제 접합에서, 접합 내접원 지름이 0.18u 이상인 32개를 주요 접합으로 분류했다. 이 기준은 스터디용 비교 가정이고 건축법·통로 폭을 의미하지 않는다.

선정안의 전체 바닥은 34.874u², 두 U 이상이 겹치는 면적률은 21.53%다. 접합 면적 변동계수 CV는 0.647이다. CV는 면적의 차이만 요약하므로 형상 다양성의 단독 평가값으로 사용하지 않았다. 확대도에서는 실제 접합을 추출해 형태, 상대 회전, 발생 위치를 함께 보았다.

모듈 간 Δθ는 120° 회전 대칭을 고려한 최소 상대각이다. 이것은 접합한 개별 날개 사이의 각도와 같지 않다. 두 모듈의 전체 방향이 비슷해도 서로 다른 날개가 만나 비대칭 공유 공간을 만들 수 있다. 확대도의 작은 상대 회전 사례가 이를 보여준다.

## 중정 보존과 변경의 한계
중정 20개는 최종 바닥에서 우선 비운다. 이웃 모듈이 중정 13에 0.008749u², 중정 33에 0.000401u², 중정 42에 0.003150u² 들어온다. 이 면적을 최종 바닥에서 제거한다. 따라서 강체 원형 외곽은 이동·회전 전후 동일하지만 실제 바닥의 일부는 중정 경계에서 잘린다. 이 예외를 숨기지 않고 확대도 06에 표시했다.

전체 바닥은 하나의 연결 성분이며 0.04u 안쪽 오프셋 후에도 하나다. 각 모듈의 잘린 바닥도 하나로 연결된다. 7개의 가는 접점을 주요 연결에서 제외해도 32개 접합으로 모든 모듈을 잇는 하나의 그래프가 남는다. 이는 배치의 연결성 검사이며 실제 무장애 동선·피난·유효폭 검토가 아니다.

## 공용 오피스로 읽는 방법
가는 접점은 주요 동선으로 세지 않고 시선과 경계 조정 대상으로 남긴다. 사선 접합은 팀의 진입 방향이 바뀌는 곳, 넓은 접합은 공동 작업·협의의 장소, 세 U가 만나는 결절점은 공동 자원 공간으로 해석한다. 이번 수정은 전체 배치·중첩 형상의 발전이며, 이 배치에 맞는 가구·설비·피난 계획은 아직 확정하지 않았다.

## 표현과 검증
Figure–ground의 검정은 모든 실내 바닥이며 공유 실내도 포함한다. 흰색은 중정과 외부다. 해치는 60개 날개 레이어에서 실제 경계에 맞춰 잘린 3,989개 선분으로 구성했다. 각 날개 기준 방향에 해당 모듈의 θ를 더했다. 실제 U간 중첩 경계에만 가는 윤곽선을 추가해 복잡한 선의 교차 속에서 접합 형상을 읽을 수 있게 했다. 선의 밀도는 높이나 층수가 아니다.

Python/Shapely 기하 검사, 9개 배열의 D3 브라우저 조작·SVG 저장 검사, 9개 시드의 두 차례 시각 검토, 4배 출력 확대 검토를 수행했다. Rhino 파일은 2D 곡선 모델이며 rhino3dm 읽기/쓰기 검증을 수행했다. Rhino·Illustrator 데스크톱에서 직접 실행한 것으로 주장하지 않는다.
