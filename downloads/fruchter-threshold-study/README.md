# Fruchter House — 깊은 문턱과 열린 중심

중앙 공간을 다른 다각형으로 바꾸는 대신 **세 공간군 앞의 문턱을 깊게 만들고 열린 회랑으로 연결하는 수정안**입니다. 가운데는 비워 두고 화로의 위치를 시선의 기준으로 남깁니다. 이동과 머무름은 세 문턱에 분산됩니다.

## 다운로드 파일

- `Fruchter_Threshold_Set.pdf`: A2 가로형 2장 합본. 1장은 5단계 과정·세 대안·선정안, 2장은 최종 평면·전후 비교·문턱 상세입니다.
- `Fruchter_Threshold_Study_A2.svg/pdf/png`: 종합 보드.
- `Fruchter_Threshold_Final_A2.svg/pdf/png`: 선정 평면 상세 보드.
- `Fruchter_Threshold_Plan_Editable.svg/pdf/png`: 동선과 시선 표기를 뺀 편집용 평면.
- `*_outlined.svg`: 글자를 벡터 윤곽선으로 변환한 버전.
- `Fruchter_Threshold_Package.zip`: 위 파일과 분석 설명, 설계 데이터, 검토 기록, 글꼴을 포함한 전체 패키지.

## 이전안과의 차이

이전안에서는 가운데를 흙빛의 큰 면으로 확장했다면, 이번에는 문턱의 깊이·짧은 연장벽·머무는 턱·차양 아래 연결로 공간 관계를 만듭니다. A·B·C의 외곽 형상과 면적, 회전각을 유지하며 B만 회랑 통과 폭을 위해 약 0.11U 추가 이격했습니다. 이전 결과물은 별도 폴더에 보존되어 있습니다.

세 가지 새 대안 중 **Linked Thresholds**를 선정했습니다. 중앙의 형태적 중심은 마주 보는 공간군 사이에 남는 열린 여지이며, 실제 사용 중심은 세 문턱에 분산됩니다. 특정 새 시설의 용도는 배정하지 않았습니다.

## 편집과 인쇄

일반 SVG는 도형과 문구를 편집할 수 있습니다. ZIP의 `fonts/` 글꼴을 설치한 뒤 Illustrator에서 여세요. 폰트 설치 없이 형태를 유지하려면 `_outlined.svg`를 사용하세요. PDF도 윤곽선 버전에서 내보내 한글 폰트 대체를 피했습니다. PDF 속 글자는 검색 가능한 텍스트가 아닌 벡터입니다.

모든 페이지는 **594×420mm, A2 가로형, 흰색 배경**입니다. PDF를 실제 크기 100%로 인쇄하세요. 다섯 단계와 세 대안은 동일한 배율·방향이며, 확대 평면과 상세는 확대 비율을 따로 표기했습니다. PNG는 2800×1980px 미리보기입니다.

원본의 실측 치수가 없어 실제 건축 축척은 **NTS 비례 연구**입니다. U는 기존 A 공간군의 중심 측 변 길이를 기준으로 한 상대 단위이며 미터가 아닙니다. 회랑과 문턱은 외기에 열린 반외부 공간으로 제안했으며, 차양 구조·높이·배수와 실제 폭은 후속 검토가 필요합니다. 화로도 위치 기준이며 작동하는 옥외 벽난로 상세를 뜻하지 않습니다.

상세한 판단과 근거는 `design/analysis.md`, 모든 제안 좌표는 `design/threshold-proposal.json`, 평면 기하 검사는 `review/geometry-checks.json`에 있습니다. 주요 이동선의 벽·턱 교차가 없음을 확인했으며, 구조·피난·시공 적합성까지 검증한 자료는 아닙니다.
