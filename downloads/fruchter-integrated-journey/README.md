# Fruchter House — From Original Sketch to Shared Ground

루이스 칸의 미실현 Fruchter House 스케치에 대한 해석부터 공용 오피스의 최종 figure–ground까지 이어지는 **A2 가로 15쪽 통합본**입니다. 이전 파일은 보존하고 새 파일로 편집했습니다.

## 핵심 흐름

원본의 세 공간군과 연결 중심을 읽는다 → Rotation을 통한 Interstice를 우선 전략으로 정한다 → 벌림과 중첩의 중정을 비교한다 → 우연한 겹침을 규칙 기반 모델로 바꾼다 → M4의 삼중 영역을 비워 모듈을 만든다 → 모듈을 반복한다 → 중심별 회전과 이동을 조절한다 → 단일 배치로 복귀해 내부 돌출부만 정리한다 → 검정·선·색으로 최종 공간 관계를 표현한다.

## 페이지 구성

| 쪽 | 내용 | 근거와 역할 |
|---|---|---|
| 01 | 전체 과정 8단계 | 원본에서 최종까지 한 장 요약 |
| 02 | 원본 스케치와 A·B·C·D·E | 제공된 스케치와 이전 비례 추출 모델 |
| 03 | 전략의 수정, R0–R3 | Centrality 중심의 초기 해석에서 Rotation → Interstice로 우선순위 이동 |
| 04 | 벌림과 중첩의 중정 | 실제 저장된 중정 연구 A/B 좌표를 재도식화 |
| 05 | M1–M5 중첩 모델 | 기하 규칙, 장점, 선택하지 않은 이유 |
| 06 | 원형에서 M4로 | 정규화의 변화량, 120° 중심 배치, 공통 15° 회전, 원래 외곽 재적용 |
| 07 | 반경·회전·비움의 선택 | 9개 파라미터 조합과 4개 삭제 정책 |
| 08 | 반복 배치의 수정 | 균일 12개·연속 회전장 20개·제한 각도 격자 19개·분리 군집 18개, 이후 단일 배치 복귀 |
| 09 | 최종안 생성 과정 | 승인된 연구 모듈에서 최종 바닥까지 |
| 10 | 독립 중심의 회전 규칙 | 동일 함수에 서로 다르게 반응하는 20개 중심 |
| 11 | 내부 경계 정리 | 9곳, 원래 바닥의 약 1.40% 제거; 외곽 유지 |
| 12 | 검정 figure–ground | 공유 영역을 포함한 실내 바닥과 비움 |
| 13 | 방향별 선 중첩 | 승인된 해치 드로잉 |
| 14 | 컬러 figure–ground | 업무 바탕·실제 중첩·제안 공유 연결을 구분 |
| 15 | 공용 오피스로의 해석 | 실제 겹침 3곳의 활용 제안과 확대도 |

09–15쪽은 승인된 최종본 7쪽의 도면을 유지하고, 통합본 페이지 번호·공통 머리말·내부 참조만 맞췄습니다. 앞의 도판들은 기존 결과물의 캡처를 나열한 것이 아니라 저장된 기하 좌표로 다시 그린 과정 다이어그램입니다.

## 두 가지 중첩의 차이

1. **한 모듈 안:** A·B·C 세 날개의 삼중 교집합을 비워 중정을 만듭니다. 이중 교집합은 세 공유 접점으로 남깁니다.
2. **반복된 모듈 사이:** 서로 다른 모듈이 겹치는 영역을 실내 공유 공간으로 남깁니다. 모듈 중정은 이웃 모듈이 침범하더라도 비움으로 보호합니다.

이 두 단계를 구분해야 ‘중첩은 모두 삭제해야 한다’는 오해 없이 최종 공용 바닥을 읽을 수 있습니다.

## 원본·해석·가설

- 원본 스케치 이미지는 사용자 제공 **「1106 장승환 표현기법 발표자료.pdf」 2쪽**의 PDF 표시 상태를 렌더링했습니다. 선을 생성하거나 임의로 보완하지 않았습니다. 원본 아카이브 소장 번호는 확인하지 않았습니다.
- 공간군과 전략의 설명은 **1023 발표 3–6쪽**, **1106 발표 3–7쪽** 및 이전 A3 해석 모델을 참고했습니다. A·B·C·D·E는 연구자의 해석 구분입니다. D의 지붕 또는 개방 여부를 확정하지 않았습니다.
- 벌림·회전·중첩의 발전은 **1106 발표 9–15쪽**과 이전 작업 데이터에 근거합니다. 자료의 명령 문구를 새 작업 지시로 취급하지 않고 연구 기록으로 읽었습니다.
- M4는 원본을 그대로 회전시킨 모양이 아닙니다. 원래 세 군의 합계 면적을 유지하며 1.25u × 0.80u 공통 직사각형으로 정규화한 설계 가설입니다. 개별 면적은 A −1.25%, B +2.82%, C −1.46% 바뀝니다.
- 초기 연구의 상대 단위 `U`와 정규화 이후 `u`는 정의가 다릅니다. 각 비교 도판 안에서는 공통 축척을 적용하지만, 전체 여정 요약은 단계별 맞춤 크기입니다. 실측 축척·방위·높이를 주장하지 않습니다. R0–R3는 원래 영상 좌표계에서 +각도가 시계 방향이며, M4 이후는 수학 좌표계에서 +각도가 반시계 방향입니다.
- 주거에서 도서관·공유작업실을 검토한 뒤, 최종 단계에서는 사용자 지시에 따라 공용 오피스로 해석했습니다. 세부 프로그램·동선·지붕·구조·치수·수용 인원은 확정 설계가 아닙니다.
- 검정은 벽체 포셰가 아니라 실내 바닥입니다. 가는 선은 모듈 경계의 흔적입니다. 컬러 지도에서 마젠타는 제안 연결 띠이며 치수 검증된 피난 동선이 아닙니다.

## 파일과 편집

- `Fruchter_Integrated_Journey_A2.pdf`: 15쪽 최종 통합본.
- `Fruchter_Journey_Overview_A2.pdf`: 01쪽의 전체 과정 한 장 요약.
- `output/*.svg`: Illustrator 편집용 벡터 도판. 일반 SVG는 글자 편집 가능.
- `output/*_outlined.svg`: 문자가 윤곽선으로 변환된 호환용 도판.
- `output/*.pdf`, `output/*.png`: 개별 A2 PDF와 2800 × 1980 PNG.
- `Fruchter_Integrated_Contact_Sheet.png`: 전체 15쪽 미리보기.
- `assets/`: 원본 스케치의 PDF 렌더, Noto Sans KR·Instrument Sans 글꼴과 라이선스.
- `source/`: 각 단계의 고정 데이터 사본과 출처·해시 기록. 과거 데이터의 높이·벽체 등 부가 필드는 당시 가설이며 이번 통합본에서 사실로 채택하지 않았습니다.
- `design/`: 승인된 최종안의 좌표·연결선·검증 결과.
- `scripts/`: 재생성 코드. `pip install -r requirements.txt` 후 `python scripts/integrated.py`, `python scripts/package_integrated.py` 순서로 실행합니다.

모든 도판은 흰 바탕의 594 × 420mm A2 가로형입니다. 인쇄 시 실제 크기 100%를 사용하세요. PDF는 RGB이며 인쇄소 지정 PDF/X·CMYK 프로파일을 적용하지 않았습니다. 원본 스케치 이미지 외 새 다이어그램은 벡터입니다.

원본 스케치의 래스터 해상도는 제공된 발표자료에 의존합니다. SVG에 포함된 해당 이미지는 벡터 원본으로 바뀌지 않으며, 새 다이어그램의 선·면·문자는 편집할 수 있습니다.
