# Fruchter House — Shared Ground

승인된 20개 모듈 배치를 유지하며, 내부 돌출부를 정리한 최종 드로잉과 생성 과정을 담은 A2 가로형 편집본입니다. 공용 오피스는 설계 가설입니다.

## 읽는 순서

1. **Process** — 반복 → 회전 → 중첩 → 내부 정리 → 공용 공간으로 해석.
2. **Rotation Rule** — 두 기준점의 영향으로 이동하고 회전하는 20개 독립 중심. 변화 계수 0 / 0.5 / 1의 비교.
3. **Interior Refinement** — 승인된 외곽과 배치를 보존한 내부 경계 정리 전후와 3개 확대도.
4. **Figure–Ground** — 실내 바닥과 비움.
5. **Directional Hatch** — 세 날개와 전체 모듈의 방향이 중첩되는 선 드로잉.
6. **Colored Figure–Ground** — 업무 바탕, 실제 교집합, 제안 공유 연결을 분리한 컬러 지도.
7. **Office Reading** — 실제 겹침 3곳을 공동 작업·교류·휴식의 후보로 읽는 확대도.

## 색과 선의 의미

- 인디고 `#283858`: 실내 업무 바탕. 벽체 포셰가 아닙니다.
- 로즈 `#BD6174`: 서로 다른 두 모듈의 실내 영역이 겹친 부분.
- 진한 로즈 `#923653`: 세 모듈이 겹친 부분.
- 마젠타 `#D52B82`: 제안하는 공유 연결 띠. 피난 경로나 치수 검증된 복도가 아닙니다. 정리 과정 도면에서는 같은 강조색이 제거 부분을 뜻하며 해당 장에 별도 설명했습니다.
- 흰색: 보존된 중정·사이 공간·외부.
- 가는 내부 선: 실제 모듈·날개 경계의 흔적. 새로운 벽을 의미하지 않습니다.

## 기하와 설계 해석

이 반복 모듈은 Fruchter House의 공간군·방향 관계에서 출발해 발전시킨 M4 연구 모듈입니다. 원본 주택의 정확한 실측 형태를 복제했다는 주장이 아닙니다.

20개 모듈의 위치와 회전각은 승인된 COUNTER-1.00 배치 그대로입니다. 내부 비움 31곳 중 오목한 경계를 가진 9곳에서 주변 꼭짓점을 잇는 최소 볼록 경계로 돌출부를 제거했습니다. 제거량은 원래 바닥의 1.3965%입니다. 외곽선과 20개 모듈 중정은 같고 바닥은 하나로 연결됩니다.

20개 모듈의 중심 중정은 세 날개가 만나는 중첩에서 비워낸 부분입니다. 이 **모듈 내부의 비움**과, 여러 모듈을 배열했을 때 발생하는 **모듈 사이의 공유 중첩**은 서로 다른 단계입니다. 이번 컬러 지도에서는 후자를 실내에 남겨 공유 공간 후보로 읽습니다.

공유 연결은 승인된 바닥을 0.085u 안쪽으로 물린 영역 안에서 가시성 그래프의 최단 경로로 생성한 두 개의 도식적 연결선입니다. 선택된 내부 끝점 네 개를 잇는 제안이며, 모든 모듈의 출입 동선을 해결한 평면은 아닙니다. 연결 띠 반폭 0.065u는 표현용 상대값입니다. 중정·외부를 침범하지 않는 것은 기하 검사로 확인했습니다.

`u`는 상대 단위입니다. 실제 길이, 구조, 층고, 가구 배치, 실별 출입구, 피난과 접근성은 후속 건축 평면에서 검토해야 합니다. 이 파일은 발표용 공간 재구성 최종본입니다.

## 편집과 인쇄

- `Fruchter_Shared_Ground_Final_A2.pdf`: 594 × 420mm, 가로형 7쪽. 인쇄 시 실제 크기 100%.
- `output/01_Process.svg`부터 `output/07_Office_Reading.svg`까지: 각 장의 라이브 텍스트와 벡터 레이어. Illustrator에서 열고 수정할 수 있습니다. 아래 실제 파일명은 `01_Process.svg` 등입니다.
- `output/*_outlined.svg`: 문자를 윤곽선으로 변환한 호환용 SVG. 글자 내용 편집에는 일반 SVG를 사용하세요.
- `output/Clean_Black`, `Clean_Line`, `Clean_Color`: 제목 없는 독립 드로잉. SVG·PDF·PNG를 제공합니다.
- PNG는 2800 × 1980픽셀 미리보기입니다. 대형 인쇄에는 벡터 PDF/SVG를 사용하세요.
- SVG에는 선/면/중첩/동선/문자 레이어가 분리돼 있습니다. 폰트는 `assets/`의 Noto Sans KR와 Instrument Sans이며 라이선스를 함께 넣었습니다.
- PDF는 RGB 벡터 문서입니다. 인쇄소 지정 CMYK 프로파일이나 PDF/X 규격으로 변환한 파일은 아닙니다.

## 재생성과 검증

Python 3.11 이상과 `shapely`, `numpy`, `fonttools`, `cairosvg`, `pymupdf`, `Pillow`가 필요합니다. 스크립트는 네트워크에 접속하지 않습니다.

```sh
python scripts/final.py
python scripts/package.py
```

`design/validation.json`은 기하 검증 결과, `design/final-geometry.geojson`은 레이어별 폴리곤(실제 지리 좌표가 아닌 로컬 u 좌표), `design/pivots.csv`는 모듈 중심·각도, `design/routes.json`은 제안 연결선 좌표입니다. 검정 면과 선 드로잉의 제목 없는 PNG는 승인받은 두 이미지와 픽셀 단위로 동일함을 확인했습니다.

원본 자료와 이전 프로젝트 파일은 수정하지 않고 이번 최종 편집본을 별도로 저장했습니다. 제공된 도시 지도 사례에서는 figure–ground의 레이어 구분과 색에 의한 연결 강조 방식만 참고했습니다. 실제 도시의 대지·가로·시설은 이 설계에 추가하지 않았습니다.
