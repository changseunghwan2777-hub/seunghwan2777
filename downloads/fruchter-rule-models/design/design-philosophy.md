# Measured Relations

반복의 기준을 눈에 보이게 만든다. 같은 단위와 같은 축척 위에서 중심, 축, 접점이 어떻게 변하는지 정밀하게 겹쳐 읽는다. 결과의 윤곽보다 생성 규칙의 일관성을 먼저 드러낸다.

흰 바탕은 비움과 여백의 기준이다. 회색은 개별 단위, 흙빛은 공유, 붉은색은 중첩의 집중을 맡는다. 색상과 해치가 서로 보완하도록 세심하게 조율하여 단색 출력에서도 공간 등급을 구분한다.

굵은 경계는 실제 제안 공간을, 가는 축선과 점선은 생각의 도구를 표현한다. 문턱에서 선을 정확히 멈추고, 선의 교차가 실제 통로인 것처럼 보이지 않게 검토한다. 전문적인 정밀함은 이런 접합부의 공들인 처리에 있다.

선택한 안과 보류한 안을 같은 크기로 놓는다. 도판의 여백과 글자 위계를 정돈하되 선택의 비용을 숨기지 않는다. 기하가 증명하는 내용과 설계자의 판단을 분리하는 태도가 전체 표현의 완성도를 만든다.
