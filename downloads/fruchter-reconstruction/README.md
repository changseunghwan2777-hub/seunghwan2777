# Fruchter House — Spatial Reconstruction Study

Louis I. Kahn의 Fruchter House(1951) 스케치와 기존 분석 도면을 출발점으로 만든 공간 재구성 제안입니다. **TYPE B — Activated Interstice**를 최종안으로 선정했습니다. 기존 세 공간군의 외곽 형상과 면적을 유지하면서 회전·이격하고, 그 사이의 틈을 넓혀 진입과 분기의 새로운 중심으로 삼았습니다.

## 파일 안내

| 파일 | 내용 |
|---|---|
| `Fruchter_Reconstruction_Set.pdf` | A2 가로형 2장 합본: 종합 보드 + 최종 평면 상세 |
| `Fruchter_Reconstruction_A2.*` | 기존 분석, 다섯 변형 단계, 세 대안, 선정안, 전후 비교를 담은 종합 보드 |
| `Fruchter_Reconstruction_Final_A2.*` | 선정 평면 확대, 전후 비교, 중심의 정의, 회전·이격 수치와 문턱 설명 |
| `Fruchter_Reconstruction_Plan_Editable.*` | 동선·설명 표기를 덜어낸 선정 평면 편집용 도면 |
| `*_outlined.svg` | 글자를 벡터 윤곽선으로 변환하여 폰트 없이 열 수 있는 SVG |
| `design/reconstruction.json` | 원형 좌표, 세 대안의 변환 규칙, 경계·개구부·동선 데이터 |
| `design/analysis.md` | 근거, 대안별 해석, 선정 이유와 설계 가설 |
| `review/geometry-checks.json` | 형태·면적 보존, 경계 유효성, 연결과 동선 검사 결과 |
| `fonts/` | 편집용 SVG에서 사용하는 글꼴과 OFL 사용 허가문 |
| `manifest.json` | 패키지 내부 파일의 크기와 SHA-256 |

`Fruchter_Reconstruction_Package.zip`에는 위 자료가 모두 들어 있습니다. 기존 Fruchter House PDF와 3D 모델은 수정하지 않았으며, 이 패키지는 새 평면 연구 결과입니다.

## Illustrator에서 편집

1. 문구를 수정하려면 `fonts/`의 Noto Sans KR과 Instrument Sans를 설치하고 일반 `.svg`를 엽니다.
2. 글꼴 환경에 영향을 받지 않고 도형을 편집하려면 `_outlined.svg`를 엽니다. 이 파일은 글자도 벡터 도형입니다.
3. 모든 SVG의 도면 선과 채움은 벡터이며, 페이지 배경은 흰색입니다. SVG 그룹은 단계·대안·설명별로 나뉩니다.
4. PDF는 윤곽선 변환 버전에서 내보냈습니다. 글꼴 대체 없이 출력되며, PDF 속 한글은 검색 가능한 텍스트가 아닌 벡터 윤곽선입니다.

## 출력과 배율

- PDF 용지: **594 × 420mm, A2 가로형**. 인쇄 시 실제 크기 100%를 선택합니다.
- 다섯 단계와 세 대안은 같은 배율·도면 방향을 사용합니다.
- 종합 보드 오른쪽 선정안은 세부를 읽기 위해 약 1.96배 확대했습니다. 상세 보드의 전후 비교 두 도해는 서로 같은 배율입니다.
- 원본에 실측 치수가 없으므로 **NTS 비례 연구**입니다. 실제 건축 축척이나 북향은 확정하지 않았습니다.
- PNG는 2800 × 1980px 미리보기입니다. 인쇄에는 벡터 PDF를 사용합니다.

## 분석과 제안의 구분

원본의 독립적인 세 공간군, 비정형 연결부, 진입 마당과 화로의 관계를 출발점으로 삼았습니다. A=개별실군, B=공유실군, C=식사·서비스군, D=연결 중심, E=진입 마당은 기존 분석의 명칭입니다. 새 시설의 프로그램을 지정한 것이 아닙니다.

TYPE A는 기존 D의 중심성을 강화하고, TYPE B는 진입 측 사이 공간을 중심으로 활성화하며, TYPE C는 문턱 앞 중심들을 순환 연결합니다. TYPE B는 회전 → 틈의 형성 → 중심의 이동이라는 인과관계를 가장 명확하게 드러내므로 선정했습니다. I1·I2·I3는 각각 방향 조정의 틈, 진입·분기의 넓은 장, 두꺼운 문턱을 뜻하며 고정 용도의 방이 아닙니다.

각도·이격·벽 두께·개구부·문턱 폭·외피 표현·새 중심의 위치는 **설계 가설**입니다. U는 기존 A의 중심 측 변 길이를 기준으로 한 상대 단위이며 미터가 아닙니다. G는 A+B+C+사이 공간의 면적중심(E 제외), F는 제안한 주요 동선의 집중점입니다. 구조·높이·지붕·법규 적합성은 확정하지 않았습니다.

## 확인한 사항

세 대안 모두 A·B·C의 외곽 형상과 면적을 보존합니다. 공간군끼리 중첩되지 않고, 주요 문턱을 통해 이동 공간이 연결됩니다. 표시한 주요 동선이 벽을 가로지르지 않는지 기하적으로 검사했습니다. 이는 구조·피난·시공 적합성을 검증한 결과는 아닙니다.

원본 스케치와 현재 도판을 시각적으로 비교했으며, 독립 검토에서 도면의 중대한 겹침·잘림은 발견되지 않았습니다. 검토 의견에 따라 공간군 명칭과 선 종류의 범례를 추가했습니다.
